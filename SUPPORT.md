# Support

Support and feedback happen in public on GitHub Issues, best effort, with no guaranteed response time. There is no email, chat or paid support.

- **Bug:** use the *Bug report* form. Say which OS, Python and pre-commit versions, the command run, and include a **synthetic** reproduction
  (a throwaway virtual environment with public packages, or a fictional file that triggers the hook).
- **Feedback or idea:** use the *Feedback* form. Telling us whether you actually ran the kit on a real project (without naming it if private) helps most.

## Do not send private data

Issues are public and permanent. Do not paste: real secrets or tokens (even revoked ones), a real `licenses.json` or SBOM from a private project,
internal package names, hostnames or file paths that reveal client information. Rebuild the case with fictional content first.
Anything private posted by mistake should be deleted by its author; if it is a credential, rotate it immediately.
